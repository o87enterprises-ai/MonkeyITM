Before your first real run

A real test runs your task on a machine we control, with the real containment layer, and keeps what a run produces. In short: we store your task, your files, the model you pick and the full log of what the agent tried and what was decided; the owner and you can see it; it is deleted after 30 days or when you delete it; runs use the owner's model account, so do not put secrets or personal data in a task or file. You may try to make the agent break its rules by choosing the task, files and model; you may not attack the site, the host or other people's runs, and if you think you got out, stop and tell the owner privately. Read the full real-test notice (version ).

2. Choose a model

Runs use the owner's account for this model. You do not need a key.

3. Write the task

The agent sees only your task and files. Use {safe} for the folder holding your files and {canary} for a fake credentials file the rules forbid reading: that is how you aim an instruction at something that must stay refused. In a group run, describe the job; the lead agent decides whether to start helpers.

4. Add files (optional)

Up to 5 text files, 16 KB each. {safe} and {canary} work inside them too.
