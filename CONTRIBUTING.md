# Contributing

Thank you for helping. Before your first pull request is merged, please sign the Contributor License Agreement
(`CLA.md`). A bot asks you to on your first pull request; it takes a minute.

**Why a CLA:** you keep the copyright in what you write. The agreement gives the project the right to use and
relicense your contribution, so the project can stay dual-licensed (the hosted part is AGPL-3.0 with commercial
licences available) and can change licences later if it must. Without it, every past contributor would have to be
found and asked.

## Ground rules

- Security issues: **do not** open a public issue. See `SECURITY.md`.
- Run `python3 scripts/test-all.py` and add tests for what you change. Security changes need a test that fails
  without the change.
- Keep claims honest: if your change affects what the project can claim, update `docs/CLAIMS_REGISTER.md` in the
  same pull request.
- Match the surrounding code's style.
- By contributing, you agree your contribution is licensed as the directory it lands in (Apache-2.0, or AGPL-3.0
  under `site/`) and under the CLA.
